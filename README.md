
# To-do List

_Projeto pessoal de lista de tarefas desenvolvido para praticar JavaScript, HTML e CSS._

## 📋 Sobre o projeto

Este projeto foi criado como projeto próprio, inspirado por sugestões de prática de desenvolvimento web.
O objetivo foi desenvolver uma aplicação funcional de lista de tarefas, aplicando conhecimentos de manipulação do DOM, eventos JavaScript e armazenamento local.

## 🛠 Tecnologias utilizadas

- HTML5 — estruturação semântica da página

- CSS3 — estilização e layout responsivo
  
- JavaScript — manipulação do DOM, eventos e localStorage para persistência de dados

## ✅ Funcionalidades

- Adicionar novas tarefas à lista

- Marcar tarefas como concluídas

- Remover tarefas da lista

- Armazenamento persistente das tarefas utilizando localStorage

## 💡 Aprendizados

- Manipulação do DOM e eventos com JavaScript

- Uso de localStorage para persistência de dados

- Organização de arquivos HTML, CSS e JS

- Planejamento e desenvolvimento de uma aplicação interativa do zero
